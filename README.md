# AURA-hotels-DataProject
Dashboard de Business Intelligence para el sector hotelero basado en el estándar USALI. Analiza la rentabilidad financiera (P&amp;L, GOP), Revenue Management (ADR, RevPAR) y la eficiencia de canales entre 2023 y 2025 mediante un modelo en estrella en Power BI, DAX y datos sintéticos en Python.
